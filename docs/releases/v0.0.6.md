### 新增

- **更新前可查看更新日志**：检测到新版本时，设置 → 关于 会显示「查看更新内容」入口，弹窗内展示版本号、发布日期与更新说明，确认后再执行更新；GitHub 不可达时自动降级，不打扰使用。
- **GitHub 网络访问三档设置**：设置 → 网络 新增「始终使用代理 / 自动（优先直连，失败再走代理）/ 不使用」三档策略，代理前缀可自定义；内置「测试连接」（仅 HEAD 探测，不会真实下载）。境内服务器安装 Skill 失败时，来这里配置即可。
- **登录页项目介绍**：桌面端左侧展示 slogan、项目简介与 4 条能力点（书签与标签 / Skill 管理 / 账号库 / 数据自持），移动端自动收起为单列。

### 修复

- 侧栏模块双高亮：`/accounts` 路由下「书签」不再与「账号库」同时呈选中态。
- 页面底部黑边：修复浅色 / 暗色主题下滚动到底部、移动端地址栏收起时露出黑边的问题。
- 卡片标题被左上角多选框遮挡：标题行整体右移避让，常显与悬停状态均不重叠。
- 标签跨模块串数据：书签与 Skill 的标签字典完全隔离，同名标签可各自独立存在（数据库自动迁移，详见升级提示）。

### 优化

- 侧栏标签 / 平台区排版：收紧凑进、每级分隔线，父子层级更清晰；顶部新增「全部」入口；悬停才显示「更多操作」按钮，不悬停时显示计数。
- 筛选反馈：点击左侧标签 / 平台后，右侧只展示对应内容，顶部不再显示筛选横幅；再次点击已选项即取消筛选。
- 卡片布局：标题固定单行不换行，描述 / 标签 / 底部区块固定槽位，同排卡片纵向对齐；字段为空但可见时保留空槽。
- 分页「每页条数」改为产品内下拉菜单（9 / 24 / 48 / 96），切换后回到第 1 页并清空已选。
- 侧栏折叠 / 展开增加约 200ms 平滑过渡，尊重系统「减少动态效果」设置。
- 非安全上下文提示：HTTP 访问时，登录页与账号库锁定屏提示「账号库加密与复制不可用，请使用 HTTPS」。

### 升级提示

- 本版包含 `tags` 表结构迁移（新增 `module` 列，唯一索引改为 `(module, title, parent)`）。迁移首次启动时自动执行、可重复执行、失败自动回滚；**升级前建议备份 `storage/link_navigator.db`**。
- 被 Skill 引用的历史标签会复制为 `skills` 副本，书签侧标签原样保留，数据不会丢失。
- 代理设置只影响 Skill 安装 / 更新检查对 `github.com` / `codeload.github.com` 的访问，不影响书签 / 账号库接口；`.git` 内始终保存原始 GitHub 地址。
- 应用更新检查可通过 `APP_UPDATE_CHECK=false` 关闭（设置页保存后以数据库配置为准）。
