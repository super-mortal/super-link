# v0.1.0 发布说明

## 新增

- **服务器监控模块**（独立路由 `/servers`）：Hub + link-agent 长连接架构，agent 主动外连 Hub，NAT 后无需公网 IP；四态状态（在线 / 离线 / 已暂停 / 等待连接），连接断开秒级感知。
- **列表页**：beszel 同款卡片——状态点 + 名称 + 分组、系统信息行、CPU / 内存 / 磁盘行内 meter（65/90 与 80/90 阈值变色）、网络 / 运行时长 / 容器数、最后回传时间；侧栏分组筛选（家庭 / 公网 / 公司 / 归档，带计数）。
- **详情页**：CPU / 内存 / 网络趋势图（recharts，1h / 6h / 24h / 30d 四档，默认 6h，统计行显示当前 / 峰值 / 均值）、磁盘各挂载点用量条、Docker 容器资源表（CPU / 内存 / 网络）、Agent 版本落后提示。
- **服务器管理**：添加（弹窗生成 Token + 一键复制的安装命令）、编辑、暂停 / 恢复、重置 Token（旧 Token 立即失效）、删除（级联清理全部历史数据）；Token 仅在添加 / 重置弹窗内完整展示一次。
- **link-agent**：Go 静态二进制守护进程（零第三方依赖、约 5–9MB、常驻内存约 10MB），采集 CPU / 内存 / Swap / 磁盘 / 网络 / 负载 / 开机时长 / Docker 容器，systemd 托管、开机自启。
- **安装脚本**：经 `GET /content/install-agent` 下发，自动识别 amd64 / arm64，下载对应二进制并强制 SHA-256 校验，自动写入配置并启动服务。
- **CI 发布产物扩展**：同一版本 tag 同时构建 Docker 镜像与 `link-agent-linux-amd64` / `link-agent-linux-arm64`（含 `.sha256`），挂同一 GitHub Release。

## 修复

- 框架层：非对象 JSON 请求体（数字 / 字符串 / null）统一返回 400 JSON 信封，不再以 500 HTML 暴露（影响全部 JSON 端点，含 agent 回传）。

## 优化

- 数据保留：明细数据保留 30 天，到期自动清理（不建聚合表）；30 天档图表由服务端按小时聚合返回。
- 安全：Agent Token 服务端仅存 SHA-256 + 每服务器随机盐哈希；无效 Token 与不存在服务器返回完全一致的 401；回传字段白名单 + 范围校验 + 单包上限。
- 文档：README 新增服务器监控小节；AGENTS.md 补全模块架构要点。

## 升级提示

- **Hub 前置反代需调大超时**：长轮询单次持有约 50 秒，nginx / Caddy 需同步调大 `proxy_read_timeout`（如 60s 以上）。
- **被监控机要求**：Linux + systemd；安装命令在「添加服务器」弹窗内一键复制，到被监控机执行即可。
- **数据库自动迁移**：新增五张表（servers / server_metrics / server_disks / server_docker / server_connections），升级无需手动操作。
- **Docker 部署**：安装脚本已随镜像内置（`/var/www/html/agent/install-agent.sh`），无需额外挂载。
