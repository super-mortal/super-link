# v0.1.1 发布说明

## 新增

- **板块级备份与恢复**（设置 → 数据备份）：书签 / Skill / 服务器 / 账号库四个板块各自独立导出与恢复，备份文件名统一为 `super-link-<module>-YYYYMMDD.json`。
- **恢复预检**：写库前先展示「新增 / 更新 / 同名 / 跳过 / 失败」分类与逐条预览；支持合并（默认）与覆盖两种模式，覆盖前二次确认。
- **服务器备份**：导出配置与 Token 哈希 / 盐，不含历史指标；Hub 地址不变时恢复后 agent 可直接继续连接，无需重装。备份文件等同凭据，界面有醒目提示。
- **Skill 备份**：只备份 GitHub 来源的安装地址与描述，恢复时按来源地址重新拉取最新版本；本地上传的 Skill 不受影响。
- **账号库备份**：沿用 `.slvault` 端到端加密文件，导入前在浏览器校验主密码。
- **侧栏平台 / 分组三点菜单**：hover 行显示三点，可把色点改成调色板颜色或恢复默认；颜色只存浏览器本地偏好，不入库、不参与筛选。
- **应用更新进度反馈**：更新弹窗内展示阶段式进度条，并以 `installed_version` 是否变化作为唯一成功判据。

## 修复

- 侧栏标签区 / 平台区的「全部」行移除：无选中即全部，再次点击已选项取消筛选（服务器分组区原本就没有该行，三板块行为统一）。
- 标签三点菜单里的「颜色」子菜单不再被父容器裁剪、父菜单不再一闪即关。
- 旧导出接口 `GET /api/export/data` 只导出书签标签，不再混入 Skill 标签。
- 服务器恢复的覆盖模式在事务内执行，失败整体回滚；`Repository::deleteServer()` 支持被外层事务嵌套调用，不再重复开启事务。
- 页面 / 详情 / 设置 / 弹窗 / 下拉面板的滚动条隐藏后仍可正常滚动（此前部分容器滚动条突兀）。

## 优化

- **侧栏第二区统一外壳**：标签 / 平台 / 分组共用同一套头部（固定 2rem、动作位固定顺序与不可见占位）与行几何（行高、左槽、色点、计数），切换模块或开关搜索时列表不再跳动。
- **行内细节**：三点按钮与计数中心对齐、颜色加深；父级与叶子标签名称左对齐；平台补品牌色点，分组补固定色点。
- **界面细节**：编辑书签表单改为「标题 → 网址 → 描述 → 备注 → 标签」；平台输入由原生 `datalist` 换成 combobox（可输入可选）；账号卡片常用平台显示品牌 Logo；服务器备注卡常驻可添加 / 编辑 / 清空；服务器详情头部运行时长移到第二行，长 IP 不再错位；卡片右上角操作默认 45% 可见、hover 完全显现；Skills 模块不再显示标签搜索入口。
- **图标**：服务器模块图标由 `ServerCog` 改为 `Server`。
- **备份接口形态**：预检响应为扁平分类 `{ new, same, skipped, updated?, failed? }` + 逐条预览，执行响应为 `{ items, summary }`；设置页分区名统一为「数据备份」。

## 升级提示

- **数据库无结构变更**：本轮不新增表、不改列，升级无需手动迁移。
- **旧备份文件**：不带 `module` 字段的旧文件仍可通过旧导入接口 `POST /api/import/data` 恢复（按书签处理）；新的恢复端点要求文件带 `module`，建议用新版导出的文件。
- **服务器备份含凭据**：备份文件包含各服务器的 Token 哈希与盐，请与备份文件分开妥善保管，勿上传到公开网盘或聊天工具。
- **覆盖模式不可逆**：覆盖会清空备份外的数据（服务器覆盖还会删除备份外服务器及其历史指标），执行前请确认预检结果。
- **Skill 恢复依赖 GitHub**：受设置页「GitHub 网络访问」三档策略影响；不可达时逐条失败，其余条目继续。
- **更新进度条为时间估计**：容器重建期间服务短暂不可达属正常，最终以版本号变化为准。
