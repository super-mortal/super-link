# v0.1.2 发布说明

## 新增

- **待办模块**：侧栏「书签」下方新增待办入口，徽章显示未完成数。顶部常驻快速输入，打开即可写、回车即存、自动记录北京时间（单条上限 200 字）。支持列表 / 卡片两种布局（默认卡片，按模块记忆），列表按「今天 / 昨天 / 更早」分段、最新在上。
- **已完成区与筛选**：勾选后进入底部可折叠的「已完成」区，按完成时间倒序；侧栏「未完成 / 已完成」可点击筛选，再点取消。
- **待办搜索与清理**：支持按文字搜索（含已完成）；单条删除与「清除已完成」都要二次确认。
- **服务器列表双视图**：列表页支持卡片 / 列表切换（默认卡片）；列表视图为单行摘要，含状态、系统信息、CPU / 内存 / 磁盘进度条，窄屏按 1100 / 860 / 640px 逐级收起次要信息。
- **设置页「分组」分区**：账号库分组与服务器分组统一在设置页新增 / 重命名 / 删除；非空分组禁止删除并提示数量，至少保留一个分组。
- **Skill 安装进度**：GitHub 安装改为后台任务，安装弹窗展示真实阶段（连接 / 克隆 / 校验 / 写入）与已用时长，失败停留在出错阶段。

## 修复

- 新增未连接服务器后，卡片出现空白块与两行异常信息。
- 服务器暂停 / 恢复的操作提示与页面头部重叠。
- 主密码设置失败提示过于笼统：HTTP 非安全上下文下直接说明原因并禁用入口，其他失败展示具体错误。
- 更新内容弹窗的 Markdown 未渲染，显示原始标记（`#` 标题、`**加粗**`、`*` 列表）。
- 分页底部「共 N 条项目」与左右控件不在同一水平线。

## 优化

- **账号库**：移除顶部分组筛选条（分组只在设置页管理）；卡片右上角操作改为悬浮才显示；平台与分组徽章移入徽章行；移除收藏功能（前端、接口、表结构与备份字段一并下线）。
- **侧栏**：移除标签区搜索按钮（与顶部全局搜索重复）；服务器分组行改为字典驱动，无「全部」行。
- **服务器卡片**：无快照时显示占位块、隐藏空系统信息行、页脚文案去重，分组移入页脚状态行；占位里的「查看接入指引」可点击进入详情。
- **表单**：服务器 / 账号表单的分组改为下拉选择，并在维护提示里指向设置页。
- **备份恢复**：恢复时遇到字典外分组自动建组，并在恢复结果里提示新增分组数。
- **分页**：宽屏下每页条数 / 共 N 条 / 页码三栏同一水平线，中间严格居中；窄屏堆叠。

## 升级提示

- **数据库自动迁移**：本轮新增 `todos`、`server_groups`、`skill_install_tasks` 三张表，并移除 `accounts.favorite` 列；升级后首次请求自动完成，无需手动操作。
- **待办不纳入备份**：备份与恢复仍是书签 / Skill / 服务器 / 账号库四个板块，待办数据不导出、不恢复。
- **服务器分组改为字典**：从固定四项改为可管理字典，首次升级会把已有分组名回填进字典；被删除的种子分组不会被自动复活。
- **账号库旧备份**：旧 `.slvault` 文件仍可导入，`favorite` 字段会被忽略。
- **Skill 安装**：安装改为后台任务，同来源 / 同名的进行中任务会被拒绝；超时 10 分钟自动置为失败并清理。
